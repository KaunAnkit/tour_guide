# Ambedkar Speech Media

- Place `.mp3`, `.wav`, and other audio files in `audio/`.
- Place `.mp4`, `.mkv`, and other video files in `video/`.
- Preserve original media files unchanged; do not convert, compress, rename, or re-encode them.
- Record each item's title, speaker, date (if verified), source URL, attribution/licensing information, and description.
- Later, BODH will extract transcripts and timestamps from these files for searchable retrieval.
